# Scheda Push + ABS

Scheda dedicata ai muscoli di spinta: petto, spalle, tricipiti e addome. La logica e combinare multiarticolari, isolamento e lavoro addominale con recuperi differenziati.

## Punti chiave

- Focus: petto, spalle, tricipiti e addome.
- Recupero: 2 minuti sugli esercizi pesanti, 60-90 secondi sugli altri.
- Intensita: rallentare la discesa a 3-4 secondi se i push-up diventano facili.
- Usare buffer di 1-2 ripetizioni dal [[cedimento-muscolare]] sui push-up.

## Workout Push

| Esercizio | Serie x ripetizioni | Recupero | Note |
| :--- | :--- | :--- | :--- |
| Push-up | 3 x max | 2 min | Buffer 1-2 ripetizioni |
| Military press | 3 x 8-12 | 2 min | Multiarticolare spalle |
| Floor press manubri | 3 x 10-12 | 90 sec | Spinta orizzontale |
| Alzate laterali | 3 x 12-15 | 60 sec | Isolamento deltoidi |
| Overhead extension manubrio | 3 x 10-12 | 90 sec | Tricipiti |
| Triceps pushdown elastici | 3 x 12-15 | 60 sec | Tricipiti |

## Workout Addome

| Esercizio | Serie x ripetizioni | Recupero |
| :--- | :--- | :--- |
| Sit-up con sovraccarico | 3 x 12-15 | 60 sec |
| Russian twist con peso | 3 x 16-20 | 60 sec |
| Crunch agli elastici | 3 x 12-15 | 60 sec |
