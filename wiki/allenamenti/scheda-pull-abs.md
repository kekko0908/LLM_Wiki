# Scheda Pull + ABS

Scheda dedicata ai muscoli di tirata: schiena, bicipiti e addome. La progressione e basata sul completamento delle serie al massimo delle ripetizioni previste.

## Punti chiave

- Volume: 4 esercizi schiena, 3 bicipiti, 3 addome.
- Progressione: aumentare il carico quando tutte le serie raggiungono il massimo delle ripetizioni.
- Recupero: 2 minuti per multiarticolari, 60-90 secondi per isolamento.
- La tecnica deve mantenere controllo e [[rom]] utile.

## Workout Schiena

| Esercizio | Serie x ripetizioni | Recupero | Note |
| :--- | :--- | :--- | :--- |
| Rematore bilanciere sopramano | 3 x 8-12 | 2 min | Tirare verso l'ombelico |
| Lat pulldown in ginocchio con elastici | 3 x 8-12 | 90 sec | Gomiti verso i fianchi |
| Trazioni a terra proni | 3 x 10-12 | 90 sec | Tirata orizzontale |
| Superman a terra | 3 x 12-15 | 60 sec | Contrazione lombare 2 sec |

## Workout Bicipiti

| Esercizio | Serie x ripetizioni | Recupero |
| :--- | :--- | :--- |
| Curl manubri in supinazione | 3 x 8-12 | 90 sec |
| Curl a martello | 3 x 8-12 | 90 sec |
| Reverse curl manubri | 3 x 10-12 | 90 sec |

## Workout Addome

| :--- | :--- | :--- |
