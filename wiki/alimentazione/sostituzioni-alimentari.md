# Sostituzioni alimentari

Tabella pratica per sostituire alimenti senza rompere la logica del piano. Le sostituzioni sono organizzate per funzione: proteine, carboidrati, grassi e pasti rapidi.

## Punti chiave

- Sostituisci alimenti con altri della stessa categoria nutrizionale.
- Mantieni simile la quota proteica nei pasti principali.
- Nei giorni di calcio preferisci carboidrati digeribili e grassi bassi prima della partita.
- Aggiorna questo articolo con cibi preferiti e cibi da evitare in [[vincoli-e-preferenze]].

## Proteine

| Se manca | Sostituzioni possibili | Nota |
| :--- | :--- | :--- |
| Pollo | tacchino, pesce bianco, bresaola | fonti magre |
| Tacchino | pollo, tonno, uova | scegliere in base al pasto |
| Pesce bianco | pollo, merluzzo, tonno | tenere grassi bassi |
| Bistecca magra | carne trita magra, vitello, pollo | controllare condimenti |
| Yogurt greco | ricotta magra, whey, uova | dipende da digestione |

## Carboidrati

| Se manca | Sostituzioni possibili | Nota |
| :--- | :--- | :--- |
| Riso | pasta, patate, pane | modulare quantita |
| Pasta | riso, farro, patate | scegliere in base a sazieta |
| Pane | patate, riso, gallette | utile pre-partita |
| Avena | pane, pancake proteici, cereali semplici | colazione |
| Banana | pane/miele, frutta digeribile | pre o post workout |

## Grassi

| Se manca | Sostituzioni possibili | Nota |
| :--- | :--- | :--- |
| Noci | mandorle, olio evo, salmone | dosare per calorie |
| Mandorle | noci, olio evo | evitare prima del calcio |
| Salmone | pesce bianco + olio evo | separa proteina e grassi |

## Pasti rapidi

| Situazione | Opzione |
| :--- | :--- |
| Poco tempo a pranzo | pane integrale + tacchino + frutta |
| Post-workout rapido | whey + banana |
| Cena leggera | bresaola + insalata + pane |
| Giorno riposo | yogurt greco + frutta secca dosata |
